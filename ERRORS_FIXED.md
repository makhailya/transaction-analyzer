# Найденные и исправленные ошибки

## 1. Ошибки типов (mypy) — 4 ошибки

### 1.1 `src/reports.py` — отсутствие аннотаций типов
- **Файл:** `src/reports.py:12`
- **Ошибка:** `Function is missing a return type annotation` — функция `save_report` не имела возвращаемого типа
- **Файл:** `src/reports.py:17`
- **Ошибка:** `Function is missing a return type annotation` — внутренняя функция `decorator` не имела аннотации
- **Файл:** `src/reports.py:19`
- **Ошибка:** `Function is missing a type annotation` — `wrapper` не имел аннотаций параметров
- **Исправление:** Добавлены аннотации `-> Callable`, `*args: Any, **kwargs: Any`, импортирован `Any` из `typing`

### 1.2 `src/services.py` — возврат Any вместо float
- **Файл:** `src/services.py:14`
- **Ошибка:** `Returning Any from function declared to return "float"` — `requests.get().json()` возвращает `Any`
- **Исправление:** Добавлено `data: dict` и явное приведение `float(data["rates"]["RUB"])`

## 2. Ошибки тестов (pytest) — 4 ошибки

### 2.1 `tests/test_services.py` — сравнение JSON-строки с числом
- **Файл:** `tests/test_services.py:24-25`
- **Ошибка:** 3 параметризованных теста `test_investment_bank` сравнивали JSON-строку (результат `investment_bank`) с числом `expected`. Функция возвращает JSON, а тест ожидал число.
- **Исправление:** Добавлен `json.loads()` — сравнение `result["saved"]` с `expected`

### 2.2 `tests/test_reports.py` — отсутствие столбца `Дата операции` в фикстуре
- **Файл:** `tests/test_reports.py:11-16`
- **Ошибка:** Фикстура `fake_df` содержала столбцы `Категория` и `Сумма операции`, но `spending_by_category` требует `Дата операции`, `Категория` и `Сумма платежа`
- **Исправление:** Заменены столбцы фикстуры на `Дата операции`, `Категория`, `Сумма платежа` с корректными тестовыми данными

## 3. Ошибки аннотаций типов в тестах (mypy/Pyright) — 20+ функций

### 3.1 Все тестовые функции — отсутствие `-> None`
- **Файлы:** Все файлы в `tests/`
- **Ошибка:** Тест-функции и фикстуры не имели аннотаций типов (`Function is missing a return type annotation / type annotation`)
- **Исправление:** Добавлены `-> None` для тестов, `-> pd.DataFrame`, `-> list`, `-> dict` для фикстур

### 3.2 `test_reports.py` — неиспользуемые параметры
- **Файл:** `tests/test_reports.py:63`
- **Ошибка:** Параметры `transactions`, `category`, `date` в `fake_report` не использовались
- **Исправление:** Заменены на `*args: object, **kwargs: object`

### 3.3 Все тестовые функции — отсутствие аннотаций параметров
- **Файлы:** Все файлы в `tests/` (~20 функций)
- **Ошибка:** Параметры тестовых функций (фикстуры, моки, `tmp_path`, `caplog`) не имели аннотаций типов
- **Исправление:** Добавлены `pd.DataFrame`, `list`, `dict`, `MagicMock`, `pytest.LogCaptureFixture`, `object`

### 3.4 `src/services.py` — Any из dict.get()
- **Файл:** `src/services.py:28-29`
- **Ошибка:** `t.get("Дата операции")` возвращал `Any | None`, ожидался `str`
- **Исправление:** Добавлены аннотации `date_str: str | None`, `amount: Any | None`

## 5. Ошибки окружения (не устранены — требуется обновление пакетов)

### 5.1 Pandas segfault на Python 3.14
- **Файлы:** `tests/test_views.py`, `tests/test_reports.py` (тесты с `pd.to_datetime`)
- **Ошибка:** `SIGSEGV` в `np_datetime.cpython-314-darwin.so` при вызове `pd.to_datetime()`
- **Причина:** Несовместимость pandas 2.3.2 с Python 3.14.6 (C-расширения падают)
- **Решение:** Дождаться обновления pandas или использовать Python 3.13

### 5.2 Проблемы с вендорными типами pandas-stubs
- **Ошибка:** `Type 'complexfloating' doesn't define '__str__' or '__repr__'` и аналогичные для `date`, `datetime`, `datetime64`, `floating`, `integer`, `Timedelta`, `timedelta`, `timedelta64`, `Timestamp`
- **Причина:** Несовместимость pandas-stubs 2.3.2.250827 с pandas 2.3.2 на Python 3.14
- **Решение:** Ожидать обновления stubs

### 5.3 `.venv` — сломанное окружение
- **Файл:** `.venv`
- **Ошибка:** `.venv` является пустым файлом вместо виртуального окружения
- **Решение:** Удалить `.venv` и пересоздать через `poetry install`
